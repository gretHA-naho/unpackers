### iths.gif

Keep going with either path — the notes thread or the walkthrough below.

1. Fork the sample repository into your own account.
2. Clone the fork and copy `config/example.yaml` to `config/local.yaml`.
3. Add a section for your own data set and reload the page.
4. Open a pull request once the diff reads right.

- New to the tool? Start with the [walkthrough notes](https://openacd.dev/notes).
- Read the [packaging guide](https://openacd.dev/packaging) before shipping a build.
- Browse [other tracks](https://openacd.dev/tracks) once this one is done.
- Bring questions to the [community thread](https://openacd.dev/thread).
